## Definition of done

- CONTENT-SYSTEM.md exists: pillars, format mix for the platform, posting cadence, hooks bank (20+).
- 30 days of posts drafted, every one through the de-slop loop and the hook audit.
- Visual pipeline working where the platform needs it (images generated, captions legible on phone).
- A weekly operating loop the human can run in 30 minutes (review, schedule, read the numbers, feed winners back).

## Phases

### Phase 0: Niche and pattern research (fresh session)
Paste:
> Read HARNESS.md and PROCESS-CORE.md. Research before writing: per HARNESS.md config, either extract patterns from the user's winning posts or study 5 top accounts in the niche (public content only). For each pattern log: hook type, structure, length, topic angle, why it works on THIS platform. Then define 3-4 content pillars tied to what the account is for (audience growth toward what end?). Write CONTENT-SYSTEM.md.

USER GATE: approve the pillars. A month of content on the wrong pillars is a wasted month.

### Phase 1: Hooks bank
Paste:
> Write 30+ hooks across the pillars using the researched patterns. Audit each as a cold scroller: would the first line stop the thumb? Kill the bottom third. The survivors (20+) go in CONTENT-SYSTEM.md tagged by pillar and format.

### Phase 2: The batch, with per-post loops
Paste:
> Draft all 30 days: each post = hook from the bank + body in the platform's native format + CTA where it earns one. Per post: de-slop loop, then the platform audit (right length, formats like line breaks/carousel slides/caption+image correct, reads native not cross-posted). Batch in weeks; re-read each week's set together for repetition drift.

### Phase 3: Visuals (where configured)
Paste:
> Generate the visual per post that needs one, against a single style anchor defined once (palette, composition rules, text-overlay style). Audit each at phone size: legible, on-brand, consistent with the set. Video posts get scripts routed through the video harness short-form path.

### Phase 4: Operating loop handoff
Paste:
> Produce the calendar (post, day, time in the account's timezone), a scheduling note for the user's tool of choice, and WEEKLY-LOOP.md: the 30-minute weekly ritual (approve next week, read this week's numbers, tag winners, feed winning patterns back into CONTENT-SYSTEM.md). Verify all 30 posts + visuals exist per PROCESS-CORE.md before reporting done.
