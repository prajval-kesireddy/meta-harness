Prescription, not a pile of links.

Directories list tools. Giant packs bundle everything. metaharness prescribes which skills to install, how to run them, when to switch models, and where the gates stop the agent from declaring victory too early.

01 — the interview

Say what you're making

Start with the non-code outcome: website, video, deck, research, launch, social, docs. Each path asks three or four questions up front. Follow-ups come later, only at gates where you have something concrete to react to.

02 — the composition

The harness gets built

Minimal skill installs (more makes agents worse), a staged runbook, Opus for taste calls, Sonnet for loops, Haiku for bulk where it fits, and the usage budget written down before any work starts.

03 — the loops

Loops until it's actually good

Design loops audit real screenshots. Research loops run until two dry rounds. Verification gates demand the render, live URL, citations, or evidence before anything gets called done. Annoying? Yes. Useful? Also yes.
