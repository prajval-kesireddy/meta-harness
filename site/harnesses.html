Use with Claude

The harness explorer.

Every harness states its interview up front and shows the exact machine it builds: stage by stage, the model each stage runs on, and what it takes to exit. In your own Claude it goes further and tailors all of this to you.

opus = taste and judgment stages · sonnet = production loops · haiku = bulk passes

Website

2–10 agent-hours typical

A designed, deployed website that does not look AI-generated.

4 questions. That's the whole interview. (Follow-ups come later, at gates where you have something to react to.)
Q1
Do you have any websites you want to copy or take inspiration from? (URLs, or 'none')
free answer
Q2
What type of site? (single page, multi-page, or a web app)
Single page / Multi-page / Web app
Q3
Do you already have visual assets (logo, photos, illustrations), or should they be generated?
Have assets / Generate them for me
Q4
What else do you want? (anything: copy written for you, a specific vibe, dark mode, a form, 'nothing')
free answer
Then the pipeline runs:
opus
1. Taste lock
Art direction in words: type pairing, palette, layout personality, one signature move. Reference capture if a URL was given.
opus
2. Copy
Final human-quality prose before any layout exists.
opus
3. Type & tokens
Font pairing loaded and proofed at real sizes; spacing scale and color system locked as CSS tokens.
sonnet
4. Build
Semantic structure, mobile-first, real content. Multi-page: one subagent per page against the locked system.
sonnet
5. Design loop
Screenshot 1440px and 390px, audit against the written checklist, fix top 3, repeat.
sonnet
6. Motion
Scroll reveals, hover states, one signature interaction; reduced-motion respected.
sonnet
7. Verify & ship
Lighthouse 90+, deploy, re-audit the LIVE url.

Video

2–11 agent-hours typical

A finished rendered video: explainer, promo, or short-form.

3 questions. That's the whole interview. (Follow-ups come later, at gates where you have something to react to.)
Q1
What kind of video?
Motion-graphic explainer/promo / AI-generated footage / Short-form social clips
Q2
Target length?
Under 60 seconds / 1-3 minutes / 3-10 minutes
Q3
Voiceover?
No VO / AI voiceover / I'll record my own
Then the pipeline runs:
opus
1. Script & beats
Beat sheet: timestamp budget, visual, VO/text line, purpose per beat. De-slopped.
opus
2. Style frames
One designed still per key beat locks the look before motion exists.
sonnet
3. Production
One test beat end to end, then all beats.
sonnet
4. Frame loop
Extract stills at every beat boundary, audit composition + legibility + continuity, re-render affected beats.
sonnet
5. Audio & pacing
VO/music placed, levels sane (-14 LUFS for social), cuts land on beats, attention-drop moments tightened.
sonnet
6. Final render & verify
Target-res render + phone-preview render; play the actual file, spot-check sync at 3 points.

Pitch deck / presentation

1–6 agent-hours typical

A designed deck (.pptx or PDF) that reads investor-grade, not clip-art.

3 questions. That's the whole interview. (Follow-ups come later, at gates where you have something to react to.)
Q1
What's the deck for?
Fundraising / Sales / client pitch / Internal / class / talk
Q2
Roughly how many slides?
Under 12 / 12-30
Q3
Existing brand (colors/fonts/logo), or create one?
Have brand assets / Create a look for this deck
Then the pipeline runs:
opus
1. Narrative
The deck as a 10-15 sentence story, one takeaway sentence per future slide, evidence named per claim.
opus
2. System & heroes
Slide system (type pair, 3 colors, grid, motif) + the 3 hardest slides designed first.
sonnet
3. Batch build
Every remaining slide strictly against the system; honest-chart rules on all data.
sonnet
4. Consistency loop
All slides rendered as one strip; cross-slide alignment drift is the machine-deck tell.
sonnet
5. Export & verify
Open the real exported file, fonts intact, headlines read as a story in order.

Rough length?
Under 10 pages / 10-40 pages / 40+ pages
Q3
Output format?
Designed PDF / Word doc / Markdown / web
Then the pipeline runs:
opus

Define the reader, then every section with its one-sentence takeaway and target length.
sonnet
2. Research
Runs before drafting when research-backed: source ledger, claim->source->date.
opus

The hardest section drafted first and de-slopped until genuinely human; its patterns extracted to VOICE.md.

Remaining sections one at a time against VOICE.md; fresh session per section past 10 pages.

Full read as the defined reader: transitions, repeats, voice drift, payoff placement.
sonnet
6. Typeset & ship
Render every page to image, audit margins/orphans/figures, fix, re-render.

Deep research report

2–8 agent-hours typical

A genuinely researched answer to a hard question, with receipts.

3 questions. That's the whole interview. (Follow-ups come later, at gates where you have something to react to.)
Q1
How deep?
Landscape scan / Decision support / Exhaustive deep-dive
Q2
Any must-check source types?
General web is fine / Community/social too / Academic/technical papers
Q3
What form should the answer take?
Tight memo / Scored recommendation / Full report
Then the pipeline runs:
opus
1. Question discipline
Falsifiable restatement, sub-questions, sweep lanes, expected findings written BEFORE searching.
sonnet
2. Sweep rounds
Every lane in parallel, each blind to the others; findings logged to the source ledger; gap question re-sweeps.
sonnet
3. Adversarial verify
Every load-bearing claim gets a refutation attempt: counter-search, incentive check, date check.
opus
4. Synthesis
Answer first with confidence levels, then reasoning, then receipts. De-slopped.
opus
5. Completeness critic
One fresh pass: what angle, source type, or stakeholder did we never look at?

ICP targeting

2–11 agent-hours typical

Figure out exactly who buys (your ideal customer profile), find them, and say the right thing to each segment.

3 questions. That's the whole interview. (Follow-ups come later, at gates where you have something to react to.)
Q1
Do you have customers already?
Yes, paying customers / Users/pilots, not really paying / No, starting from theory
Q2
How will you reach them?
Cold email / DM / Content / inbound / Sales team / partners
Q3
How many target accounts/people do you need?
50-100 / Several hundred / 1,000+
Then the pipeline runs:
opus
1. Evidence mining
Best-customer mining (or problem-intensity logic), triggers, and voice-of-customer language captured verbatim.
opus
2. Profile & segments
The falsifiable ideal-customer profile: firmographics, trigger, pain in their words, disqualifiers. Then 2-4 segments scored by fit and reachability.
sonnet
3. List building
Named accounts/people per segment on the free-tier stack: search-only discovery, cheap enrichment, dedup, score.
opus
4. Message-market fit
Per-segment messaging in the buyer's mined language: the pain named their way, proof, one clear ask. De-slopped hard.
opus
5. Test kit & handoff
The hypothesis test: which segment, what sample, what reply rate settles it, and the 3 assumptions outreach must answer.

Competitive analysis

2–10 agent-hours typical

A real map of your market: who's winning, why, and where the opening is.

3 questions. That's the whole interview. (Follow-ups come later, at gates where you have something to react to.)
Q1
What are you analyzing competition for? (one line: your product/idea + who it's for)
free answer
Q2
How wide should the net go?
Direct competitors only / Full landscape / Standing watch
Q3
What decision does this feed?
Should I build this / keep building? / How should I position against them? / Market sizing / is this market real?
Then the pipeline runs:
opus
1. Market frame
Decision-relevant axes (never generic feature grids), sweep lanes incl. the last-90-days freshness lane.
sonnet
2. Discovery sweeps
Every lane in parallel: sites, GitHub velocity, ProductHunt/HN, app stores, community threads, review sites.
sonnet
3. Verify & profile
Fetch each survivor's actual site/repo: positioning verbatim, pricing, traction receipts, 2-3 real threads. Kill the dead and misremembered.
opus
4. Gap mining
The complaint surface across all competitors: what buyers keep asking for that nobody ships.
opus
5. Verdict
Decision answered first with confidence; map; profiles; differentiation surface; the honest where-you-lose section.
