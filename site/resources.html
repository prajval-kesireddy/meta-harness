The $300 image-generation stack nobody claims.

Resources are the second input: the stuff that renders your pixels, voices, and clips. The full rated resource marketplace is coming. This guide ships first because it's the single biggest free unlock: Google Cloud hands every new customer $300 of credit, and pointed at Gemini image generation on Vertex AI that's a serious asset pipeline for zero dollars.

$300Google Cloud new-customer credit, valid 90 days
~2,2002K-resolution images at $0.134 each (gemini-3-pro-image)
~4,500Higgsfield credits' worth of comparable stills (2 credits per image there)

Step 1: Claim the credit

Create a Google Cloud account at cloud.google.com/free. The $300 credit is Google's standard offer for new customers; it applies automatically and covers Vertex AI. A card is required for verification, and nothing bills until you explicitly upgrade after the trial, so the worst case is the credits just expire.

Step 2: One-time setup

  1. Create a project in the Cloud console and enable the Vertex AI API for it.
  2. Install the gcloud command line tool (cloud.google.com/sdk).
  3. Authenticate with application default credentials, which is the part almost everyone skips:
gcloud auth application-default login

Why this matters: the AI Studio API keys people usually grab are ephemeral and die mid-run, which is how most "my image script stopped working" stories end. Application default credentials refresh themselves. Set it once and every script on your machine just works.

Step 3: Generate

Call gemini-3-pro-image through Vertex AI. The request that matters, stripped to its bones:

POST https://aiplatform.googleapis.com/v1/projects/YOUR_PROJECT/locations/global
     /publishers/google/models/gemini-3-pro-image:generateContent

headers:  Authorization: Bearer <token from application default credentials>
          x-goog-user-project: YOUR_PROJECT
body:     {"contents":{"role":"USER","parts":[{"text":"your prompt"}]},
           "generationConfig":{"responseModalities":["TEXT","IMAGE"],
           "imageConfig":{"aspectRatio":"16:9","imageSize":"2K"}}}

The image comes back base64 inside candidates[].content.parts[].inlineData.data. Two practical rules from real runs: generate in pairs with a ~25 second pause (bursts of four hit rate limits and the image simply never arrives), and retry single failures rather than re-running the whole batch.

What it's worth

At $0.134 per 2K image, the credit buys roughly 2,200 images. On Higgsfield, a comparable still runs 2 credits, so the same output would take around 4,500 credits there, several months of a paid plan. Both belong in a real pipeline (Higgsfield's model catalog, motion tools, and character consistency features earn their credits); the point is sequencing: burn the free $300 first, spend credits where the free tier can't follow.
